# 📱 HavenHub Mobile App

The resident and staff portal for the HavenHub Property Management System. Built with **React Native** and **Expo**, this app provides a smooth, cross-platform experience for modern property interactions.

## ✨ Key Features
- **Instant Service Fee Payments**: Real-time integration with payment gateways for hassle-free collections.
- **Community Wall (Notice Board)**: Stay updated with the latest community announcements, notices, and bulletins.
- **Role-Based Workflows**: Tailored experiences for Owners, Residents, and Staff members.
- **Real-Time Notifications**: Never miss an update with Firebase-powered push notifications.

## 🛠 Tech Stack
- **Framework**: [Expo](https://expo.dev/) (React Native)
- **Styling**: [NativeWind](https://nativewind.dev/) (Tailwind for React Native)
- **Navigation**: [React Navigation](https://reactnavigation.org/)
- **API**: Axios with JWT authentication
- **Push Notifications**: Firebase Cloud Messaging (FCM)

## 📥 Getting Started

1. Navigate to the App directory:
   ```bash
   cd Estate_link_App
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npx expo start
   ```
4. Use the Expo Go app or a physical device/emulator to preview.
